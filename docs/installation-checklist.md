# PartyOps 1.4.2 安装与上线检查清单

适用于 Windows 10/11 x64、UOS V20 amd64/arm64 的主机与协同机。当前 `v1.4.2-rc.1` 为候选版，未关闭项不得勾选为通过。

## 制品

- [ ] 文件来自同一个 GitHub Release，没有使用聊天附件或二次转存文件。
- [ ] 平台与架构正确：Windows x64、UOS amd64 或 UOS arm64。
- [ ] SHA-256 与 Release 清单逐字一致。
- [ ] 正式版 Windows Authenticode、DEB/更新包发布签名有效；发布者符合预期。
- [ ] Release 同时提供版本说明、迁移/回滚、SBOM、第三方声明与验收记录。

## 主机

- [ ] 使用本机可靠磁盘；数据目录不在 NAS、共享盘或云同步目录。
- [ ] 生产环境、演示数据关闭、SQLite 严格能力检查开启。
- [ ] 绑定明确的可信局域网地址，不使用 `0.0.0.0`、公网 IP 或路由器端口映射。
- [ ] 浏览器 HTTPS 与 Agent 双向 TLS 均开启，证书/私钥权限最小化。
- [ ] 更新包与模型包公钥由部署端预置，私钥不在主机、源码或制品中。
- [ ] 防火墙只对专用网络/可信网段开放 `18765/18766`。
- [ ] 首任管理员只在主机本机创建，密码已进入单位密码管理流程。

## 协同机与权限

- [ ] 使用限时入网码完成设备证书登记，旧凭据失效时重新入网。
- [ ] 普通用户可选择并发布自己的真实文件夹，主机不显示协同机绝对路径。
- [ ] 团队/指定成员的浏览、下载、发送权限符合预期。
- [ ] 主机管理员可停用目录、隔离设备、撤销成员权限。
- [ ] 权限撤销后，进行中的分块传输与最终内容读取立即失败。

## 业务回归

- [ ] 四种账号/位置组合均只显示真实可用功能，无空白管理页。
- [ ] 事项、评论提及、通知、我的工作、材料版本、审核归档闭环通过。
- [ ] 档案三种访问模式、协同贡献、扫描件、字段级中文错误通过。
- [ ] 单文件、多选、文件夹 ZIP、浏览器另存为、下载到本机均通过。
- [ ] PDF/Office/文本离线阅读、超限降级与活动内容下载边界通过。
- [ ] 备份创建、下载、校验、隔离恢复与升级回滚演练通过。

## 正式放行

- [ ] 后端、前端、静态入口测试和生产构建全部通过。
- [ ] Python/前端生产依赖已知漏洞为零，许可证变化已人工复核。
- [ ] 前后端行覆盖率均达到 90%。
- [ ] Windows 10、Windows 11、UOS amd64、UOS arm64 分别通过主机/协同机真机验收。
- [ ] 20GB、断线续传、主机重启、哈希失败、权限中途撤销和 24 小时连续运行通过。
- [ ] 发布签名、升级、原位回滚、备份恢复和小范围试运行证据齐全。

任一正式放行项未完成，结论都是 **NO-GO**。详细命令与配置见[部署说明](deployment.md)和[发布就绪判定](release-readiness-1.4.2.md)。
