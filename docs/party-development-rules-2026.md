# 2026 年党员发展时间计算规则说明

最后核对：2026-08-11。运行时规则版本：`2026.05`。

## 唯一制度基线

时间计算只依据 [2026 年 5 月新版《中国共产党发展党员工作细则》](https://www.12371.cn/2026/05/18/ARTI1779102179030620.shtml)，规则与来源随程序离线内置，不依赖联网或 LLM。

| 节点 | 系统处理 | 条款 |
| --- | --- | --- |
| 收到申请书后谈话 | 提交日起一个自然月内 | 第七条 |
| 确定积极分子 | 组织研究后人工录入 | 第八条 |
| 培养考察 | 满一年后给出发展对象最早日期；每半年考察提醒 | 第十一、十三条 |
| 发展对象公示 | 不少于五个工作日 | 第十三条 |
| 政治审查、集中培训 | 结论人工录入；培训不少于三天或二十四学时 | 第十六、十七条 |
| 预审后支部大会 | 预审合格后一个月内 | 第十九条 |
| 接收预备党员审批 | 一般三个月，特殊情况最长六个月 | 第二十五条 |
| 入党宣誓 | 批准接收后一般一个月内 | 第二十九条 |
| 预备期 | 从支部大会通过之日起一年 | 第三十一条 |
| 转正决议审批 | 三个月内 | 第三十三条 |

自然月平移遇目标月份没有同日时取月末，例如 1 月 31 日加一个月为 2 月 28 日，闰年相应为 2 月 29 日。工作日优先读取 PartyOps 工作日历的节假日与调休；相关年份无配置时按周一至周五暂算并显著告警。

## 上传表格的使用边界

`入党、转正所需材料及时间顺序模板).xlsx` 只用于提取基层补充材料名称，包括“三考”、季度思想汇报、自传、备案报告及批复等。旧表中的日期公式、顺序和期限不进入国家规则引擎。

系统首次打开管理页时生成“基层补充材料参考（待管理员确认）”，默认停用。管理员只能追加材料、责任主体、说明和排序，不能覆盖国家规则日期。

## 隐私与责任边界

- 姓名和计算草稿按账号、当前设备保存在浏览器本机；不建立人员发展档案。
- 计算/导出请求只在本次处理内使用姓名；Word 发送完成后删除服务端临时文件，审计只记录规则版本、节点数和风险数。
- 结果是工作辅助，不代替组织研究、政治审查、预审、审批和档案审核。
