党建智办 PartyOps 1.4.3 更新说明

版本：1.4.3
当前候选：1.4.3-rc.8
数据库：0019
规则基线：中国共产党发展党员工作细则（2026年5月修订）

一、新增本机私有备忘录
- 文本、清单、置顶、标签、纸色、搜索、自动保存和30天回收站。
- 内容只保存在当前电脑，不进入主机、协同或系统备份。
- 支持同账号 AES-GCM 加密备份导入导出。

二、新增发展党员时间计算
- 计算法定截止、最早日期、建议窗口、实际进度和人工确认节点。
- 支持节假日/调休、暂算提示、日期顺序与超期风险。
- 导出包含条款依据和材料清单的 Word 文档。
- 单位补充材料不能改写或缩短国家期限。

三、升级与回滚
- 支持从 1.3.4、1.4.0—1.4.2 候选版升级。
- 升级前自动备份；失败恢复程序与数据库。
- 缺少正式签名或目标平台真机证据时只能作为测试候选使用。

四、rc.8 安装与启动修复
- Windows 10/11 支持本机固定磁盘上的中文、空格和非 C 盘程序目录与数据目录。
- Windows 7 x64/x86 使用独立 Python 3.8 Legacy 运行时并随附 UCRT/API-set，不依赖 Windows 10 的 path API-set。
- 麒麟、UOS、deepin 与 openEuler 的四个桌面入口统一复用固定运行时，避免共享库被安全中心当作临时程序反复拦截。
- 桌面入口启动前即创建日志；进程退出、端口未就绪、版本不符或浏览器关联失败时显示中文诊断和日志位置。
- 个人模式创建管理员前确认同版本健康端点，旧页面和旧进程不会与新服务混用。
- 新建事项支持由负责人、创建人或管理员删除，并使用并发版本校验防止误删刚被他人更新的事项。

完整说明见 README.md、docs/upgrade-1.4.3.md、docs/acceptance-1.4.3.md 和 docs/release-readiness-1.4.3.md。
