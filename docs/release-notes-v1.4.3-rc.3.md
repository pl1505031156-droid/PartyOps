# 党建智办 PartyOps 1.4.3-rc.3 发布说明

发布日期：2026-08-17
发布类型：GitHub 普通 Release（未签名候选版）

## 这一版解决了什么

- 首次使用先选“个人使用 / 这是主机 / 这是协同机”。只给自己用时选个人模式，无需管理员授权，也不会开放局域网端口。
- Windows 安装和首次配置继续支持自定义程序目录、数据目录、中文路径和带空格路径；数据库、附件、备份、证书、模型、缓存和日志都跟随数据根目录。
- Windows 单文件安装器内置固定版本的 Tesseract 5.5.3 与中英文模型，安装后无需再单独配置 OCR。
- 修复协议注册表拒绝访问造成的半安装；安装器现在先检测、再写入、最后回读，任一步失败都回滚。
- 主机服务按“注册、启动、子进程、端口、健康、局域网地址”分阶段诊断，失败不再打开空白页；首位管理员只在本机健康后创建。
- 面向新手的错误页改为稳定中文诊断码和操作建议；`WinError 786` 明确识别为单位 Windows 组织策略阻断，PartyOps 不会绕过系统策略。
- 卸载时可选保留数据或彻底删除。彻底删除必须通过归属和路径安全验证，避免高权限误删其他目录。
- 从 rc.3 开始建立专业系统内更新链：精确选包、后台下载、断点恢复、签名/大小/哈希验证、自动备份、原位安装、健康检查和失败回滚。

## 已知限制

- 所有 rc.3 安装包均未做商业代码签名；安装前请核对官网/Release 显示的 SHA-256。
- 麒麟、UOS、deepin 和 openEuler 当前没有真机安装结论。“普通 Release”只表示可直接下载，不等于稳定版或真机已通过。
- Windows 7 已终止系统级安全维护；本轮 Legacy 依赖安全门禁未通过，因此不发布 Win7 x64/x86 制品。
- rc.2 签名私钥已不可恢复，rc.2 到 rc.3 需要一次手工原位升级；不需要卸载，数据默认保留。rc.3 之后的版本可在 PartyOps 内快速升级。

## 安全与验收

本轮按用户要求未使用 Codex Security，也不依赖 Docker。发布门禁由本地全量测试、行/分支覆盖率、类型检查、生产构建、秘密扫描、SAST、依赖审计、SBOM、归档穿越检查、二进制 ABI/API 检查、冻结入口自检和本机恶意软件扫描共同组成。最终数据以同 Release 附带的机器可读发布清单和验收记录为准。
