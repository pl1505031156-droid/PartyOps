# PartyOps v1.4.3-rc.1 测试候选

发布日期：2026-08-11。数据库模式：`0018`。

> **这不是稳定生产版。** Windows 安装器尚未进行 Authenticode 正式签名；Windows 10、UOS 双架构、20GB、24 小时长稳与正式 Ed25519 更新签名仍无完整证据。请只在隔离测试环境使用，并先校验 SHA-256。

## 主要变化

- 新增严格本机私有备忘录：文本/清单、置顶、标签、纸色、搜索、自动保存、30 天回收站和 AES-GCM 加密备份。
- 新增依据 2026 年 5 月新版《中国共产党发展党员工作细则》的确定性时间计算，支持实际节点、工作日暂算、材料与风险提示。
- Word 时间轴删除“日期类型”列，日期和状态全部中文；按党政机关公文风格完成 A4 版心、标题、正文、表格和页码排版。
- 管理员可维护单位补充材料，但不能改写、删除或缩短国家规则节点。
- 修复协同 Agent 空证书路径、补充材料唯一约束、主机/协同机角色标题等发布路径问题。
