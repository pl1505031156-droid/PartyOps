# PartyOps v1.4.3-rc.2 测试候选

发布日期：2026-08-13。数据库模式：`0018`。

> **这不是稳定生产版。** Windows 安装器尚未进行 Authenticode 正式签名；Windows 10、UOS 原生安装、真实多机协作、20GB 和 24 小时长稳仍无完整实机证据。请根据官网或 Release 页面显示的 SHA-256 核对单文件安装器。

## 本轮解决的问题

- Windows 安装与首次配置均可选择本机固定磁盘数据目录，支持中文、空格和非 C 盘；UAC 后不会静默回退到 ProgramData。
- 业务数据库、附件、备份、证书、模型、缓存、日志和接收文件跟随所选目录；迁移失败保留原配置和旧数据。
- 主机服务分别报告服务注册、SCM 启动、子进程、端口、健康检查和局域网地址阶段，并把子进程输出与退出码写入轮转日志。
- 启动失败返回 `SERVICE_MISSING`、`SERVICE_STOPPED`、`CHILD_EXITED`、`PORT_IN_USE`、`DATA_DIR_DENIED`、`TLS_INIT_FAILED` 或 `HEALTH_TIMEOUT`，不会打开未就绪或空白页面。
- 本机健康检查和首位管理员创建固定访问 `127.0.0.1`，协作地址继续显示所选局域网 IP，消除首次配置的 `WinError 10061` 竞态。
- 前端打包增加完整静态资源闭包校验，覆盖入口、路由懒加载块、CSS、图片和 WebAssembly。
- UOS 双架构统一 `cryptography==50.0.0`，每个 wheelhouse 仅保留一个规范化包名实例；amd64/arm64 离线闭包分别独立严格校验。

## 下载方式

- Windows 普通用户只下载 `PartyOps_1.4.3-rc.2_windows_amd64.exe`。
- 安装器校验内部载荷；官网与 GitHub Release 直接显示文件大小和 SHA-256。
- `.sha256` 和候选 JSON 保留给自动化工具，不是普通用户安装的第二个必需文件。
- `PartyOps-UOS-1.4.3-rc.2-build-kit.zip` 是供 UOS amd64/arm64 目标机原生构建的严格离线套件，不是可直接安装的 DEB。
- UOS 普通用户同样只下载这一个 ZIP；解压后运行 `bash install.sh`，脚本先校验 ZIP 内全部输入，再构建/校验对应架构 DEB、安装并核验版本、架构、桌面入口和系统更新服务。外部 `.sha256` 不是安装必需文件。
