党建智办 PartyOps 1.4.0 更新说明

版本：1.4.0
数据库模式：0016

一、真正的协同办公
1. 获得类别“贡献”授权的协同人员，可在协同机新建、编辑重要档案，上传扫描件并建立业务关联。
2. 共享文件夹不再只允许首次配置，可随时添加、移除、重命名、查看审批状态和立即同步。
3. 主机补齐共享目录审批、用户/设备/目录授权，以及主机到设备、设备到主机、设备到设备三种传输。
4. 普通人员进入协同页可看到本机状态、我的共享目录、我的传输、接收文件和权限说明。

二、档案录入修复
1. “请检查标记字段后重试”改为具体中文字段错误，并自动定位首个错误。
2. 年份、日期、数字、下拉和长文本按类别定义校验；日期使用日期选择器。
3. 年度考核结果使用类别选项，不再错误变成自由文本。

三、收件箱与文件处理
1. 设备文件先按需拉取到受管收件箱，再预览、下载、固化或关联。
2. 收件箱可转为任务材料、档案扫描件，并记录处理状态、处理人和处理时间。
3. 搜索、复制、传输和业务关联统一校验设备、目录审批和授权，撤销权限后立即失效。

四、评论、通知与我的工作
1. 评论支持回复层级和提及，不再与事项编辑争用版本。
2. 顶栏新增通知铃铛和最近通知；通知中心可按评论、提及、指派、审核、传输和目录审批筛选。
3. “我的工作”聚合我主办、我协办、我审核和步骤分派给我。

五、Windows 与统一更新
1. 新增 Windows 10/11 x64 安装链，同一安装器可在首次向导选择主机或协同机。
2. 主机作为 Windows 服务运行；协同 Agent 按当前用户登录自启；内置 Python 和 SQLite 3.53.3，不依赖系统 Python。
3. 更新清单保留 1.3.4 兼容字段，并增加 UOS amd64/arm64 与 Windows amd64 平台制品映射。

升级说明：1.3.4 UOS 主机可导入已签名的 partyops_1.4.0.partyops-update。当前工作区只提供未签名的 Windows 验收候选包；正式统一更新包必须在 UOS 双架构原生构建完成并由隔离发布密钥签名后生成。
