# 党建智办 PartyOps 1.4.1 安装、升级与回滚

最后更新：2026-08-09

## 版本与兼容范围

- 程序版本：`1.4.1`；数据库模式：`0017`。
- 支持从正式版 1.3.4（数据库 `0015`）和 1.4.0 候选版（数据库 `0016`）直接升级。
- 统一更新清单继续使用 `format_version: 2`，保留旧 `architecture_artifacts`，并通过 `platform_artifacts` 分发 Windows amd64、UOS amd64 和 UOS arm64 制品。
- Windows 10/11 仅支持 x64；UOS/国产系统支持 amd64、arm64。所有平台首次安装时均显式选择主机或协同机角色。

## 0017 数据迁移

`0017_true_file_sharing_local_ai` 在保留现有事项、档案、附件、设备、共享根、传输和模型包的基础上执行以下变更：

- 共享根增加发布人、`team|selected` 共享范围、正文语义索引开关和发布时间，并新增共享根成员权限表。
- 设备增加“允许普通用户发布共享目录”能力；既有有效协同设备默认开启。
- 传输增加交付方式、批量项目、打包类型、结果名称和最终哈希。
- 本地模型激活拆分为 `embedding` 与 `llm` 两种能力；旧组合模型包迁移后仍可读取。

降级脚本支持 `0017 → 0016`，但降级会删除上述 1.4.1 专属字段和成员关系。正式环境优先恢复升级前备份，不应把已发生 1.4.1 新业务写入的数据库直接交给旧程序长期使用。

## 升级前检查

1. 在主机生成并验证最新 `.partyops-backup`，确保剩余空间可同时容纳业务数据、更新包和回滚副本。
2. 记录当前主机/协同机角色、设备编号、共享根和正在执行的传输；暂停大文件传输。
3. 正式环境只接受发布负责人签名且校验通过的 `partyops_1.4.1.partyops-update`。未签名 Windows 安装器仅限隔离试装。
4. 确认部署端信任的发布公钥与隔离签名环境匹配，不复制工作区历史私钥。

## UOS 主机原位升级

1. 管理员进入“管理 → 系统更新”，导入签名后的统一更新包。
2. 更新器验证 Ed25519 签名、来源版本、目标平台/架构、大小和 SHA-256，并生成升级前备份。
3. 停止服务，安装匹配架构的 DEB，执行 `0015/0016 → 0017`，再执行版本、SQLite、数据库模式和 HTTP 健康检查。
4. 主机成功后向协同机登记目标版本；协同机按 `uos.amd64` 或 `uos.arm64` 选择制品。
5. 升级后验证本机目录发布、团队/指定人员权限、浏览器与 Agent 两种下载、设备间中转及权限中途撤销。

## Windows 10/11 x64

- 首次部署使用 Authenticode 已签名的 `PartyOps_1.4.1_windows_amd64.exe`；后续升级使用同一格式的统一更新包。
- 主机数据位于 `%PROGRAMDATA%\PartyOps`；协同 Agent 配置和接收目录位于 `%LOCALAPPDATA%\PartyOps`。
- 安装器注册 `partyops-client://` 本机共享管理协议。网页签发与用户、设备绑定的 60 秒单次令牌后，才允许调用系统文件夹选择器。
- 主机服务以系统服务运行；协同 Agent 按登录用户启动。主机防火墙规则仅开放专用网络所需端口。

## 升级后验收

- 普通协同用户可以发布和管理自己的本机目录；主机普通用户只能访问团队文件，不能修改主机系统目录。
- 文件中心正确区分“主机文件”“某协同机共享”“本机共享”，并显示在线、同步和有效权限。
- 单文件、多选 ZIP、文件夹 ZIP 的浏览器另存为与当前设备接收目录均产生真实文件，最终 SHA-256 一致。
- 目录停用、成员撤销、设备隔离后，创建、分块上传和最终下载都立即拒绝。
- 管理员路由对普通用户隐藏；直接访问显示明确无权限页，不出现空白页面。
- 向量与 LLM 模型包可分别导入、激活、停用和回滚；无模型权重时系统保持规则与检索降级，不伪装为可推理状态。

## 回滚

1. 平台适配器停止 PartyOps 服务并恢复上一版本程序。
2. 对数据库执行 `0017 → 0016` 只适用于迁移刚完成且尚未产生新业务数据的场景；其他情况恢复升级前 `.partyops-backup`。
3. 重新启动上一版本，校验版本、数据库模式、共享根与附件，再解除只读恢复状态。
4. Windows 卸载会移除服务、防火墙、协议和自启项，但按设计保留业务数据目录；删除保留数据必须另行人工授权。

正式发布前必须完成 Windows 10、Windows 11、UOS amd64、UOS arm64 的主机/协同机真机矩阵，以及 20GB、断线续传、主机重启、权限中途撤销和连续 24 小时运行。
