# 党建智办 PartyOps 1.4.5-rc.3 发布说明

`1.4.5-rc.3` 从 `1.4.5-rc.2` 增量升级，数据库迁移为 `0024`。本版把公文排版改为系统内嵌流程，新增可预览、可确认、可撤销的通用台账导入和发展党员真实进度时间轴，并集中补齐删除/归档/恢复、提醒一致性、Windows 自定义路径和离线意图模型边界。

## 主要变化

- 公文规范排版不再依赖“启动助手”按钮或独立窗口；页面内完成选择、诊断、确认、排版、复检和导出，文件内容、路径、文件名和哈希不进入主机、协同机、数据库或 AI。
- 新增 `xlsx/xls/xlsb/ods/csv` 通用台账导入向导，首批覆盖发展党员、人事调动、事业编/公务员考核和任意重要档案分类。低置信映射、重复记录、日期歧义和新增字段必须人工确认；提交后可安全撤销。
- 发展党员档案使用全流程真实进度时间轴：已发生事实、法规边界、即将到期、逾期、参考预测和人工调整明确分色。补录上游事实只重算未发生节点，不覆盖历史。
- Needle 2 通过官方 C ABI 提供离线意图预览；否定词、提示注入、低置信度、无证据参数或越权工具都会回退，模型永不直接执行业务写操作。
- 用户、发展党员、会议、文档、学习计划/场次、专题、人工日志、档案类别/关联/模板、工作区目录、AI 策略、备份和模型包补齐影响预检、停用/归档、恢复或安全卸载。历史业务和审计不做破坏性物理删除。
- 修复 Windows `[INSTALL_DIR_ACL_DENIED]` 的递归误报：程序根与旧载荷分阶段保护，跨账号 UAC 只在完整安全预检后使用系统所有权回退并重新核验。
- 修复业务数据目录只能使用 C 盘的跨账号场景：日常账号可先创建 D/E 盘空目录，再由管理员原子收敛 ACL；中文、空格和非系统盘路径均保留。非空未知目录、移动盘、网络盘和重解析点继续拒绝。
- 提醒专项覆盖任务改期、发展党员节点、逾期、静默时段、周期汇总、协同隐私和桌面去重；改期后立即更新或撤销活动提醒，已读历史继续保留审计。
- 官网安装指南新增可复制的 AI 安装验证提示词，面向看不懂命令的新手逐步核对系统、架构、SHA-256、安装角色、健康状态和脱敏日志；明确禁止上传业务数据、关闭安全机制或绕过安全门禁。

## 数据迁移与回滚

- 升级前自动备份数据库、配置、证书、协同状态和数据目录标记。
- `0024` 新增台账导入任务/模板/变更、发展党员真实进度、自定义字段和生命周期元数据；旧记录保持可读取。
- 已自动验证 `0001 → 0024 → base` 完整迁移链，以及 `0023 → 0024 → 0023` 增量往返。
- 迁移或健康门禁失败时恢复数据库快照、配置、证书和上一版本二进制；不删除用户选择的数据目录。

## 安全边界

- PartyOps 不建议安装在涉密、敏感电脑上，也不得用于处理涉密文件。
- Windows 安装器没有商业代码签名；macOS 没有 Developer ID 签名和公证。首次放行前必须核对官网清单中的文件名、长度和 SHA-256，不能关闭 SmartScreen、Gatekeeper 或其他系统安全机制。
- 模型包和更新包只接受与客户端内置信任公钥匹配的正式 Ed25519 签名。平台原生运行时未验证时，模型目录显示不可用，不提供伪通用包。
