# 党建智办 PartyOps 1.2.0 安装、升级与回滚

最后更新：2026-07-31

## 版本内容

- 五域导航和统一今日工作台。
- 独立工作日历：周、月、年度节点、节假日和调休。
- 长期任务：每月、每季、每半年、每年、自定义天数；固定日、月末、季末、最后一个工作日；暂停、终止、跳过单次和临时改期。
- 任务、文件、档案、日志、报告、知识、联系人、专题的双向关联和活动时间线。
- 周/月/季/年汇总幂等投影、失败可见和人工重建。
- 五域上下文帮助、主机数据库保存学习进度。
- 运行诊断增加数据库完整性、双端口、设备版本和投影状态。
- 数据库迁移到 `0013`。

## 已安装 1.1.3 的推荐升级

正式发布包通过 UOS 双架构和签名验收后：

1. 主机管理员先创建手动备份，并确认第二台电脑已拉取灾备副本。
2. 进入“管理 → 系统更新”。
3. 导入 `partyops_1.2.0.partyops-update`。
4. 核对发布签名、版本 `1.2.0`、数据库模式 `0013` 和更新说明。
5. 点击“开始升级”。主机会自动备份、升级程序、迁移数据库并健康检查。
6. 主机成功后，在线协同电脑收到匹配架构的升级任务；离线电脑下次上线继续。
7. 低版本协同电脑在升级完成前不能进入业务页，完成后自动重新进入。
8. 主机在设备中心确认所有启用设备均显示版本一致。

不要解压 `.partyops-update`，不要在终端执行其中内容，也不要把发布私钥放入安装目录。

## 新电脑首次安装

```bash
dpkg --print-architecture
```

- 输出 `amd64`：安装 `partyops_1.2.0_amd64.deb`。
- 输出 `arm64`：安装 `partyops_1.2.0_arm64.deb`。

双击对应 `.deb` 后输入管理员密码。安装完成会生成唯一的“党建智办”桌面图标。主机选择真实局域网 IP；协同电脑粘贴主机生成的完整一次性入网信息。

## 修复性安装

仅在旧电脑更新助手损坏、正式 `.partyops-update` 无法执行时，才使用同架构 `.deb` 原位修复：

```bash
sudo apt install --reinstall ./partyops_1.2.0_amd64.deb
```

ARM64 将文件名换为 `partyops_1.2.0_arm64.deb`。不要先卸载，不要删除 `/var/lib/partyops`，禁止 `--force-architecture`。

## 回滚

1. 记录系统更新页的失败任务编号并导出脱敏诊断包。
2. 停止继续写入，保留升级前 `.partyops-backup`。
3. 由更新助手恢复旧版 Debian 包和升级前数据库/附件快照。
4. 运行 SQLite 完整性、外键和附件抽样检查。
5. 主机恢复后再允许协同电脑连接。

如更新助手本身损坏，使用旧版同架构 `.deb` 修复程序，再从系统备份页恢复；不得手工复制 WAL 写入中的 SQLite 文件。

## 正式发布门槛

只有以下项目全部通过，才可把 1.2.0 标记为正式安装包：

- 后端和前端全量覆盖率均不低于 90%。
- UOS V20 amd64、ARM64 原生构建和安装。
- 三机共享数据、设备入网、断线重连和文件授权。
- `.partyops-update` 签名、迁移、强制版本一致和完整回滚。
- 7 天连续运行测试。
