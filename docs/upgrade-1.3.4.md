# 党建智办 PartyOps 1.3.4 安装升级与回滚

## 版本说明

1.3.4 是面向批量推广的稳定性修复版本，数据库模式继续为 `0015`。升级不会清空任务、附件、重要档案、设备证书、配对信息、备份或 AI 配置。

## 已安装电脑：使用系统内更新

1. 主机管理员进入“管理 → 系统更新”。
2. 导入已签名的 `partyops_1.3.4.partyops-update`。
3. 核对版本、更新说明、签名、磁盘空间和升级前备份结果。
4. 点击“开始升级”，等待主机完成安装、数据库检查和健康检查。
5. 协同电脑下次进入系统时显示 1.3.4 更新说明；用户点击“开始更新”后，Agent 自动安装匹配架构的软件包、自重启并重新进入系统。
6. 主机“设备协同”页面确认全部电脑均为 1.3.4；离线电脑上线后继续更新。

只有更新助手损坏时，才使用同架构 `.deb` 做一次修复性原位升级。包名仍为 `partyops`，不会生成第二个应用或第二份数据库。

## 新电脑安装

- `dpkg --print-architecture` 返回 `amd64`：安装 `partyops_1.3.4_amd64.deb`。
- 返回 `arm64`：安装 `partyops_1.3.4_arm64.deb`。
- 安装结束前会核验核心程序、桌面入口及 `partyops-updater.service`；更新助手未启动时安装器不会误报成功。
- 首次配置必须使用日常桌面账号，不得用 root 创建用户侧配置。

## 本次修复

- 设备心跳、命令轮询、目录同步和后台任务使用独立调度，不再出现“设备在线但命令不执行”。
- 协同电脑更新完成并回报结果后自动重启 Agent，立即加载新程序并解除版本门禁。
- 升级异常中断遗留的失效锁可自动恢复；仍存活的真实升级进程不会被并发覆盖。
- 一键安装新增更新助手与核心程序完整性检查，失败时输出对应 systemd 日志。
- amd64 与 ARM64 离线依赖闭包均包含 NumPy 2.2.6、ONNX Runtime 1.22.1 和 Tokenizers 0.21.4。

## 回滚

1. 从更新历史定位本次升级前备份。
2. 由更新助手恢复旧版 Debian 包和与其兼容的数据库、附件快照。
3. 健康检查完成前保持只读恢复页。
4. 若更新助手损坏，安装旧版同架构 `.deb` 后再从系统备份恢复。

正式 `.deb`、便携包和 `.partyops-update` 必须在 UOS V20 amd64 与 ARM64 目标机分别原生构建并完成安装、原位升级和回滚验收。
