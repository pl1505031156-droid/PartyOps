党建智办 PartyOps 1.4.1 更新说明
发布日期：2026-08-09（候选验证版，正式签名发布待门禁完成）

一、真正的跨机文件共享

1. 已入网协同机上的普通用户和管理员都可以点击“共享本机文件夹”，通过系统文件夹选择器发布真实目录。
2. 支持团队共享与指定人员共享，并可分别授予浏览、下载、发送权限。
3. 文件中心统一显示主机文件、协同机共享和本机共享，支持单文件、多选 ZIP、文件夹 ZIP。
4. 支持浏览器另存为和下载到当前协同机接收目录；设备间文件仍经主机中转和哈希校验，不使用匿名 SMB 或设备直连。
5. 目录停用、成员权限撤销或设备隔离后，未完成传输会在后续分块立即停止。

二、主机与协同机界面分工

1. 页面和导航统一读取后端有效能力，不再依赖零散管理员角色判断。
2. 主机管理员负责主机目录、设备、人员授权、更新、备份和 AI 管理。
3. 主机普通用户可以浏览、下载和关联团队文件，只管理自己的传输。
4. 协同机管理员和普通用户均可发布自己的本机目录；管理员额外保留全局管理能力。
5. 普通用户直接访问管理员页面时显示明确无权限页，不再出现空白页面。

三、本地智能能力

1. 向量和 LLM 模型包可分别激活；模型权重继续采用独立签名包，不塞入主更新包。
2. BGE 中文向量采用 CLS 池化、查询前缀和模型清单约束。
3. 默认只索引业务元数据；共享目录正文必须由发布人或管理员逐目录开启，撤权后清理相应正文向量。
4. LLM 只生成带来源的草稿，不自动修改事项、档案或权限；内存不足、超时或模型缺失时安全降级。
5. Windows x64、UOS amd64/arm64 已接入固定版 llama.cpp 运行时，仍须在对应真机和正式模型包上完成发布验收。

四、升级范围

1. 版本升级到 1.4.1，数据库升级到 0017。
2. 支持从 1.3.4 正式版和 1.4.0 候选版直接升级。
3. Windows 10/11 x64、UOS amd64、UOS arm64 使用各自制品；统一更新包由平台适配器自动选包。
4. 升级前自动备份，失败时恢复程序和数据库；生产环境不得导入未签名候选包。

五、当前发布状态

源码功能和 Windows 11 x64 候选验证已进入收口阶段；覆盖率 90%、Windows 10、UOS 双架构、20GB、断线续传、24 小时运行、正式签名和模型权重包尚未全部完成，因此本说明对应候选验证，不代表正式全量发布。
