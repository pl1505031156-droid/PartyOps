# PartyOps 1.4.5-rc.3 升级与回滚

版本：`1.4.5-rc.3`；数据库迁移：`0024`；最低直接升级基线：`1.4.5-rc.2`。

## 升级前

1. 关闭重复打开的 PartyOps 页面，确认没有正在提交的台账导入、文档排版或跨机文件传输。
2. 安装器自动保存数据库、配置、内部 CA、主机证书、设备绑定、数据目录标记和当前程序快照；不要手工复制 WAL 状态下的 SQLite 文件。
3. 核对安装包平台、架构、长度和 SHA-256。Windows/macOS 未使用商业签名或公证时，按官网安全说明放行，禁止关闭 SmartScreen、Gatekeeper 或单位安全软件。
4. 协同主机记录当前监听地址、本机浏览地址和对外公布地址；`127.0.0.1`、`localhost`、`0.0.0.0` 不能作为协同公布地址。
5. 非 C 盘数据目录必须是本机固定磁盘上的真实目录。普通账号可先建立空的 D/E 盘目录，再由管理员确认 UAC；网络盘、移动盘、重解析点和来源不明的非空目录继续拒绝接管。

## 迁移 `0024`

`0024` 增加通用台账导入任务、映射模板、可撤销变更、发展党员真实进度事件、自定义字段与生命周期元数据。预测日期与实际发生日期继续分栏保存，导入文件在提交前不写业务表。

迁移已通过：

- 空数据库 `0001 → 0024 → base` 完整回放；
- 现有数据库 `0023 → 0024 → 0023` 增量往返；
- 迁移失败时数据库、配置、证书与上一版本二进制原子恢复。

## 安装与路径门禁

- 自定义程序目录先校验真实路径、固定磁盘、重解析点与上级目录，再创建并二次校验。
- 安装器先只收敛程序根目录所有权和 DACL；旧版载荷单独处理。`icacls` 无法接管跨账号创建的 PartyOps 目录时，才使用 Windows 自带 `takeown.exe` 精确接管管理员组所有权，并重新执行 DACL、完整性级别和文件回读门禁。
- `[INSTALL_DIR_ACL_DENIED]` 仅表示程序根目录本身无法安全接管；旧载荷分别使用 `INSTALL_DIR_TREE_OWNER_DENIED`、`INSTALL_DIR_TREE_ACL_DENIED` 和 `INSTALL_DIR_TREE_ACL_VERIFY_FAILED`，避免把子文件问题误报成根目录故障。
- 数据目录不会因为选择 D/E 盘而退回 C 盘。跨账号接管只允许空目录；完成根 ACL 收敛后再次确认目录仍为空，防止检查与使用之间被写入文件。

- 健康端点报告 `1.4.5-rc.3`、数据库版本 `0024` 和前端静态入口一致。
- 内嵌公文排版服务只绑定可信回环地址，文件内容不经过主机 API；成功、取消、失败和超时均清理临时副本。
- 台账导入完成全量行校验、人工映射确认、重复策略和一次撤销演练。
- 发展党员实际进度时间轴能够补录、纠正和作废事实，只重算未发生的下游计划。
- 任务改期、发展党员节点、静默时段、周期汇总和协同桌面提醒按[提醒验收矩阵](reminder-test-matrix-1.4.5-rc.3.md)复核。
- 安装目录内 `update-public-key.txt` 的 SHA-256 公钥指纹仍为 `7d9d69a006ab26add736a16d0f9eb4f3667343c63da18d7672daf5d6fa2de2a3`；更新包和模型包必须由对应私钥签名。

## 自动回滚与卸载

迁移、最终运行时启动或健康检查任一失败时，安装事务恢复上一版二进制、配置、证书和数据库快照，不删除用户数据。网络地址事务独立回滚旧地址和证书。

“仅删除程序并保留数据”不执行数据目录删除预检；完整删除预检失败时自动退回保留数据模式。禁止使用宽泛递归命令手工清理 PartyOps 目录。
