# 党建智办 PartyOps 1.4.5-rc.5 候选说明

`1.4.5-rc.5` 是基于 rc.4 的综合修复候选，数据库迁移为 `0025`。本文件描述已进入源码冻结候选的变更，不代表制品已经公开发布；最终支持等级以 `support-matrix-1.4.5-rc.5.json` 和发布验收记录为准。

## 本版修复

- UOS/麒麟协同机重新入网改用一次性专用入网请求头。普通浏览器写请求仍受 Origin/CSRF 门禁保护；入网码需同时通过格式、时效、常量时间匹配、重放、频率和 CSR 校验，删除旧协同机后可安全重新绑定。
- 用户输入的无时区日期时间统一按北京时间（`Asia/Shanghai`，`UTC+08:00`）解释，API 内部仍保存 UTC 瞬时。任务日期、提醒、周期事项与导出共享同一转换契约，避免“18:00 被显示成次日 02:00”。
- 公文规范排版继续采用 PartyOps 独立 OOXML 实现，并用用户提供的标准 DOCX 做黄金样本。DOC/WPS 只通过安装包内随附、经过来源与许可审计、架构匹配的 LibreOffice headless 运行时在本机转换；缺少闭包时构建直接失败，不再把运行时缺失留到用户电脑上。
- 重要档案台账可从文件名、工作表名、文号和日期列提出“档案年度”候选，同时展示证据来源；必须由用户确认后才落库。继续支持手动映射、批量补值、行级修订、字段创建、冲突处理和可审计撤销。
- 发展党员使用统一中文全流程时间轴；真实进度、法规期限、参考计划、逾期、人工调整和纠正记录明确区分，生产界面不再泄露 `conversation_target` 等内部英文键。
- macOS 构建改为先执行原生 Mach-O 探针，再由内向外递归签名所有 Python.framework、扩展、动态库和辅助入口，最后签主 App；混合 Team ID 返回 `MACOS_TEAM_ID_MISMATCH` 并阻止打包。未签名、未公证候选不会进入稳定更新清单。
- 官网赞助榜增加人工支持者“子木”（`2026.08`），爱发电成功回调先持久化匿名待处理事件，再按具体 `user_id` 查询昵称并用分页对账补偿。公开榜单不保存或返回金额、订单号、原始用户 ID、留言或支付渠道。

## 数据迁移与回滚

- `0025` 只迁移确认属于用户录入的旧无时区字段；服务器生成时间不改。每个变更保存原值、新值和规则版本，可在回滚演练中复原。
- 台账新增年度候选与人工修订字段，旧导入任务继续可读。
- 升级仍使用 rc.4 建立的模式无关 SQLite 在线备份事务。备份、迁移或迁移后健康检查失败时保留旧版本和诊断，不允许半迁移数据库进入业务运行。

## 安全与发布边界

- PartyOps 不建议安装在涉密、敏感电脑上，也不得用于处理涉密文件。
- 公文文件始终留在当前电脑；台账导入在用户最终确认后才进入共享主机。
- Windows/macOS 没有商业签名条件。不得通过关闭 SmartScreen、Gatekeeper 或单位安全软件规避验证。
- 当前候选尚未获得九个平台所需的 LibreOffice 原生运行时闭包与目标系统启动证据，因此不生成、不上传 rc.5 安装包，也不切换官网或在线更新；当前生产版本继续为 rc.4。

## 验证状态

源码测试、覆盖率、安全扫描和未满足的原生发布条件记录在 `docs/acceptance-1.4.5-rc.5.md`。只有九个平台的全新安装、`0024→0025` 覆盖升级、Finder/桌面启动、协同、提醒、公文转换和回滚门禁全部通过，才可创建不可变标签 `v1.4.5-rc.5`。
