# 党建智办 PartyOps 1.3.3 安装升级与回滚

## 版本说明

1.3.3 为“东方四时长卷”视觉与场景整合版本，数据库模式继续为 `0015`。升级只替换程序、前端主题映射和离线美术资源，不清空任务、附件、重要档案、设备证书、备份或 AI 配置。

## 已安装电脑：首选系统内更新

1. 主机管理员进入“管理 → 系统更新”。
2. 导入签名文件 `partyops_1.3.3.partyops-update`。
3. 核对目标版本、数据库模式、更新说明、磁盘空间和升级前备份结果。
4. 点击“开始升级”；主机完成签名验证、程序替换和健康检查。
5. 在线协同电脑收到对应架构的更新任务，用户确认后自动升级并重新进入系统；离线电脑下次上线继续更新。

更新助手损坏时，才使用同架构 `.deb` 做一次修复性原位升级。包名仍为 `partyops`，不会创建第二个应用或第二份业务数据库。

## 新电脑安装

- `dpkg --print-architecture` 返回 `amd64`：双击 `partyops_1.3.3_amd64.deb`。
- 返回 `arm64`：双击 `partyops_1.3.3_arm64.deb`。
- 安装器请求管理员密码属于正常的系统级安装流程；首次启动仍由日常桌面账号完成主机或协同电脑配置。

## 回滚

1. 在更新历史中选择本次升级记录并查看升级前备份。
2. 由更新助手恢复旧版 Debian 包，再恢复与该版本兼容的数据库和附件快照。
3. 健康检查通过前保持只读恢复页，禁止新程序继续写入旧模式数据库。
4. 若更新助手不可用，按目标架构修复安装旧版 `.deb`，随后从系统备份恢复。

## 现场验收

- 主机业务端口、Agent 端口、数据库、附件和调度器状态正常。
- amd64 与 ARM64 协同电脑版本均为 1.3.3，任务变更可在其他设备看见。
- 春夏秋冬主题、农历、节气、减少装饰和减少动态均可切换。
- 画卷不接收点击、不改变页面尺寸，滚动前后固定位置不变。
- 备份、恢复、文件授权、更新历史和失败诊断可正常使用。

正式 `.deb`、便携包和 `.partyops-update` 必须分别在 UOS V20 amd64 与 ARM64 目标机原生构建、签名并完成安装验证。
