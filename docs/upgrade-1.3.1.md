# 党建智办 PartyOps 1.3.1 安装升级与回滚

## 版本范围

1.3.1 是东方画卷增强版，数据库模式继续为 `0015`。本次只替换程序和前端美术资源，不新建数据库、不清空任务、不修改附件、档案、设备证书、备份或模型配置。

## 已安装电脑的正常升级

1. 主机管理员进入“管理 → 系统更新”。
2. 导入签名文件 `partyops_1.3.1.partyops-update`。
3. 核对版本、更新内容、签名、磁盘空间和升级前备份检查。
4. 点击“开始升级”。主机完成程序替换和健康检查后，才向协同电脑开放对应架构更新。
5. 协同电脑上线时显示 1.3.1 更新内容；点击“开始更新”后由 Agent 自动安装，成功后自动回到系统。
6. 主机“设备协同”页持续显示每台电脑的应用版本、Agent 版本和更新状态。

正常路径不需要解压源码或执行终端命令。只有更新助手损坏时，才使用同架构 `.deb` 做一次修复性原位安装；不得卸载旧版，不得删除 `/var/lib/partyops` 或用户数据目录。

## 新电脑安装

- `dpkg --print-architecture` 返回 `amd64`：双击 `partyops_1.3.1_amd64.deb`。
- 返回 `arm64`：双击 `partyops_1.3.1_arm64.deb`。
- 安装后只会出现一个“党建智办”桌面入口。
- 主机选择真实局域网地址并完成诊断；协同电脑粘贴主机生成的完整一次性入网信息。

## 回滚

升级失败时系统保留升级前备份和旧包信息。管理员先从系统更新页下载脱敏诊断，再执行回滚；回滚必须同时恢复程序包版本与对应数据库快照，禁止单独复制 `/opt/partyops` 文件。若系统更新页不可用，按 [长期运行与故障处置](operations-runbook.md) 使用受限更新助手恢复。

## 画卷验收

- 标准装饰下，主画面完整出现在页面中上部中央空白带，视觉重心位于主内容宽度 35%—70%。
- 画卷不穿过按钮、表格、输入框或正文，不拦截点击。
- “减少装饰”隐藏所有图片，但保留农历、节气和题签。
- 图片加载失败时页面布局与业务操作保持正常。
