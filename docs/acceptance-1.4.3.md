## 本轮对抗式审查已修复

- 首次管理员创建增加受保护向导令牌，并将登录、首次配置等无 Cookie 写请求纳入同源校验，阻断恶意网页接管 localhost 服务。
- 自定义程序目录在覆盖前核验祖先与现有目录 ACL；拒绝普通用户可写的旧目录，避免遗留 DLL 被 SYSTEM 服务加载。
- 自定义数据目录继续支持固定磁盘、中文和空格路径，同时在配置及每次服务启动时核验重解析点、所有者和替换权限。
- 备份 ZIP 拒绝大小写碰撞、Windows 保留名、ADS、特殊/加密成员；数据库升级回滚重新执行完整清单、哈希和 SQLite 校验。
- 模型包签名范围扩展为完整归档闭包，拒绝未登记文件、重复/碰撞成员、链接、设备和非标准压缩成员。
- 备份与模型包的 `manifest.json` 增加唯一性和 1 MiB 上限；更新包、模型包按“廉价元数据边界 → 清单验签 → 大载荷读取”处理，未受信输入不再先遍历数 GiB 载荷。
- 更新包进一步拒绝 Windows 大小写/Unicode 碰撞、保留名、ADS、加密成员、非标准压缩和异常压缩比，并返回稳定诊断码。
- 发布侧离线更新包校验器已与服务端收敛到格式 v3 目录、0019 模式、显式平台/架构映射、完整归档闭包和先验签后哈希契约，消除“构建机放行、用户上传后拒绝”的差异。
- Linux 原生包在提取便携 TAR 前执行路径、类型、权限、数量和展开体积校验，并只使用哈希一致的构建区副本。
- ARM64 冻结不再在 PyInstaller 收集阶段执行 ONNX Runtime CPU 探测；改为静态收集源码、数据和共享库，并保留制品运行时真实导入自检。
- Linux 冻结在进入依赖编译前校验共享 `libpython`，拒绝使用无法生成可启动 PyInstaller 载荷的静态解释器并输出中文根因。
- 更新、回滚、TLS 健康、Windows 注册表、服务子进程、传输临时文件与 Linux root 更新环境的既有修复继续由全量测试覆盖。

本轮按用户要求未使用 Codex Security；使用本地源码审查、故障注入、真实 Inno 编译、依赖审计与秘密扫描，门禁没有降低。
