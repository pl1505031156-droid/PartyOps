## Windows 候选制品

- 目标文件为 `PartyOps_1.4.3-rc.2_windows_amd64.exe`，普通用户只下载此一个 EXE；外部 `.sha256` 仅为可选自动化附件。
- 安装器内嵌版本、不可变标签、源码提交与内部文件清单；安装前强制全新前端构建和静态资源闭包验证。
- 主机服务初始保持手动，只有用户确认主机角色并写入所选数据目录后才切为随 Windows 启动；协同机安装不会误开主机端口。
- 安装器未做 Authenticode 签名，只能作为测试候选。最终文件大小、哈希与当前 Win11 安装闭环写入 Release 候选 JSON。

## UOS 构建输入

- amd64 与 arm64 离线闭包均通过：62 个运行/构建包、66 个 wheel；每个架构只有一个 `cryptography-50.0.0`。
- rc.2 套件在两个架构分别执行重复包、版本与闭包校验；任一语义或 llama.cpp 输入缺失都拒绝出包。
- 最终 ZIP 为 338,686,387 字节，SHA-256 `cddd27af144ccb0c189db4b209bd8a77a71011a92682d9b66b66dd7543824889`；连续两次构建字节一致，独立读取 ZIP 后确认唯一顶层目录、双架构 wheel 数均为 66、私钥条目为 0。
- ZIP 不是 DEB，不能替代 UOS amd64/arm64 真机构建和安装验收。
