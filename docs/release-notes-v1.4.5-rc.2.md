# 党建智办 PartyOps 1.4.5-rc.2 发布说明

`1.4.5-rc.2` 集中修复公文排版、运行身份、协同地址、文件预览与打开、麒麟安装、跨平台启动、卸载保护和官方更新诊断。本版数据库迁移为 `0023`；从 `1.4.5-rc.1` 升级前自动备份数据库、配置、证书和协同状态，迁移或健康检查失败时恢复快照与上一版程序。

## 公文规范排版

- “资料 → 公文规范排版”只通过随机事务标识唤起本机助手，文件内容、文件名、路径、正文、哈希和排版结果不上传主机、协同机、AI 或数据库。
- DOCX 使用 OOXML、`python-docx` 和 `lxml` 独立处理；DOC/WPS 必须依赖本机已安装且可用的 WPS、Microsoft Office 或 LibreOffice，无法可靠转换时明确停止或只导出 DOCX。
- 只提供 GB/T 9704-2012 公文格式，覆盖 A4 版心、字体字号、段落网格、28 磅行距、标题层级、附件、落款、日期、版记、页码和表格；识别不确定时要求人工确认。
- 排版后重新读取成品并复检。字体缺失、转换损坏或关键结构无法核对时不得显示“符合标准”。
- 临时目录只允许当前用户访问，导出、取消、异常或空闲十五分钟后清理。普通删除不等于取证级擦除，不得使用 PartyOps 处理涉密文件。

## 协同、文件与跨平台可靠性

- 运行身份重新配置改为本机事务和状态轮询；本机浏览地址与对外协同地址分开保存，回环或通配地址不能下发给协同机。
- 修改主机地址时保存配置和证书快照，更新 SAN，执行回环与局域网健康检查，通知已入网协同机迁移；确认失败可一键回滚。
- PDF 预览使用精确同源嵌入策略；WPS 等不支持结构化预览的格式直接转为本机打开或下载。
- 一次性文件打开授权持久化记录目标设备及创建、兑换、打开、完成、过期和失败状态，页面分别提示授权、证书、网络、助手、文件、格式和默认程序错误。
- 麒麟安装脚本快速返回，冻结运行时自检移到可观察验证服务；Windows 和 macOS 启动链在进入业务运行时前写入精确诊断。
- 卸载“保留数据”模式不执行数据目录删除预检；完整删除预检失败自动退回保留模式，禁止误删。

## 党务业务与帮助

- 发展党员快速测算直接生成全部后续节点首轮参考计划；法定边界、参考日期、人工调整和实际日期继续分别保存，上游变化只重算尚未发生节点。
- 具备对应角色权限的协同用户可以共同新建、编辑和办理重要档案、党务会议、中心组学习、发展党员和结构化业务文档。
- 帮助中心新增公文排版、协同地址、文件打开、发展党员预测、更新诊断、安装启动、卸载保护和模型签名说明；新增页面均提供唯一“本页帮助”。

## 更新与模型供应链

- 客户端分别诊断 DNS、TLS、代理、超时、HTTP、清单 JSON、签名、哈希和平台不匹配。
- 更新目录、平台安装包和模型包必须使用与 `packaging/uos/update-public-key.txt` 匹配的正式 Ed25519 私钥签名；不匹配时发布门禁整体停止。
- 正式私钥只通过发布机本地文件路径传入，不进入聊天、源码、日志、制品或网站。没有正式私钥时不生成临时签名包，也不公开模型国内直链。

## 已知限制

- Windows 安装器没有商业 Authenticode 签名，SmartScreen 信誉提示不能由应用代码可靠消除。
- macOS PKG 没有 Developer ID 和 Apple 公证，首次安装可能被 Gatekeeper 拦截；应先核对 SHA-256，再使用“隐私与安全性 → 仍要打开”，不得全局关闭 Gatekeeper。
- `.doc` 与 `.wps` 不是浏览器或 PartyOps 原生格式；本机没有可用办公套件或转换不能无损回写时只提供 DOCX 结果并明确提示。
- 各平台只有在对应原生构建、安装启动和目标系统门禁完成后才会从 `unavailable` 更新为 `preview` 或 `stable`，具体以机器可读支持矩阵和发布清单为准。

## 发布门禁

发布顺序固定为：源码冻结与本地测试 → 正式签名密钥匹配 → 原生制品构建 → Cloud Studio `/downloads/` 后台上传 → 公网完整回读并核对长度、SHA-256、文件头和版本 → GitHub `v1.4.5-rc.2` 预发布 → 官网本地构建 → EdgeOne preview → `partyops-cn-overseas` production。任何门禁失败均停止后续步骤并保留上一生产版本。
