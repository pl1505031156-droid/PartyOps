# PartyOps v1.4.2-rc.1 测试候选

发布日期：2026-08-09
发布通道：Pre-release / 测试候选
正式发布判定：NO-GO

## 本版内容

- 普通协同用户可发布和管理本机共享目录，并按团队或指定成员授权浏览、下载和转发。
- 主机文件和协同机文件统一进入文件中心，支持 DOCX、PDF、CSV 等文件的离线结构化阅读、浏览器下载和当前设备接收。
- 接入 Firecrawl AnyDoc 与 pdf-inspector 官方 WebAssembly 包，文档正文不上传第三方服务。
- 档案权限按有效能力统一计算，保留字段级中文错误，修复笼统的档案录入失败提示。
- 增加通知、提及、评论回复、“我的工作”、远端文件物化、传输固化和档案/任务材料转换。
- Windows 与 UOS 共用 1.4.2 源码和数据库迁移 0017；Windows 冻结运行时内置 SQLite 3.53.3。
