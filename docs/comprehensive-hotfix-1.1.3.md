# PartyOps 1.1.3 综合修复包说明

最后验证日期：2026-07-30。

## 本次修复

- 协同电脑入网码兼容中文标签、换行、零宽字符、BOM 和全角句点；截断码、重复码仍安全拒绝。
- 一事一档添加材料项增加写锁、版本冲突处理、21 类常用材料预设及自定义类别。
- 已完成事项即时同步到当前周、月、季度和年度报告；打开周期汇总时自动补建并同步草稿。
- 原始文件中心只读取目录、文件名、大小、类型和修改时间，不读取正文、不执行 OCR、不展开压缩包。
- 主机文件通过一次性短期授权交给 UOS 默认程序打开；`.wps` 通常由 WPS 打开。绝对路径不返回浏览器。
- 主机可以删除纳管设备。删除立即撤销令牌、目录和授权，但保留传输及审计；有未完成传输时拒绝误删。
- 所有新增/编辑窗口继续使用视口居中弹窗，1366×768 下标题和按钮保持可见。
- “系统设置 → 更新历史”在首次启动本修复后记录应用时间和以上内容。

## 覆盖安装（已有源码目录）

将以下文件复制到 PartyOps 源码目录：

```text
PartyOps-1.1.3-comprehensive-hotfix.zip
PartyOps-1.1.3-comprehensive-hotfix.zip.sha256
```

在主机执行（推荐，脚本会自动查找、校验并解压修复包）：

```bash
cd '/data/home/XHX-CXZ-0010/2026年/其他/PartyOps/PartyOps'
bash artifacts/extract-and-apply-hotfix.sh XHX-CXZ-0010
```

关键安装入口全部使用 ASCII 文件名，避免部分 UOS 解压工具把中文 ZIP 文件名显示成
“搴旂敤鏈”“涓€閿”等乱码。如果旧修复目录中还没有
`extract-and-apply-hotfix.sh`，先手动执行：

```bash
cd '/data/home/XHX-CXZ-0010/2026年/其他/PartyOps/PartyOps'
unzip -o artifacts/PartyOps-1.1.3-comprehensive-hotfix.zip -d .
bash ./apply-hotfix.sh XHX-CXZ-0010
```

脚本会从修复后的源码强制重建同架构安装包并执行原位修复，保留
`/var/lib/partyops` 中的数据库、附件、账号、备份、设备和配置。安装结束后关闭旧浏览器标签，
再双击桌面“党建智办”。

本综合修复包修复了安装/更新链路本身，因此仍属于一次性的桥接修复。主机和每台协同电脑均完成
本次桥接修复后，后续正式版本只由主机在“系统设置 → 系统更新”导入签名
`.partyops-update`；协同电脑上线时由本机 Agent 获取匹配架构的安装程序并自动完成更新，不再
逐台复制源码或运行构建脚本。

若当前以 root 登录，也必须把日常桌面账号作为参数传入；不要直接手工删除数据目录。

## 回滚

应用前先在“系统设置 → 备份”创建手动备份。若 UOS 原生构建或健康检查失败，安装器不会删除业务
数据；保留 `artifacts/one-click-install.log`，重新解压应用前的源码副本并运行原安装命令即可。
