# PartyOps 1.4.5-rc.2 升级与回滚

版本：`1.4.5-rc.2`；数据库迁移：`0023`；最低直接升级基线：`1.4.5-rc.1`。

## 升级前

1. 关闭重复打开的 PartyOps 页面，确认当前主机和协同终端没有正在写入的大文件传输。
2. 由安装器保存数据库、配置、内部 CA、主机证书、设备绑定和当前程序快照；不要手工复制 WAL 状态下的 SQLite 文件。
3. 核对安装包平台、架构、长度和 SHA-256；Windows/macOS 未使用商业签名或公证时按官网已知限制处理。
4. 存在协同机时记录当前对外公布地址。`127.0.0.1`、`localhost` 和 `0.0.0.0` 只用于本机或监听，不能作为协同地址。

## 迁移 `0023`

迁移只为旧 `FileOpenGrant` 增加目标设备、状态、兑换时间、完成时间和标准结果码；旧记录仍可读取。迁移脚本使用批次保护和幂等列检查，不能通过删除旧表或重建业务数据库实现升级。

## 安装后门禁

- 健康端点报告版本 `1.4.5-rc.2`、数据库能力和前端静态入口一致。
- 本机浏览继续使用回环地址；协同公布地址必须通过 TLS SAN 和局域网健康检查。
- 文件打开助手能创建、兑换并完成一次性授权；PDF 预览和 WPS 降级路径分别验证。
- Windows、Linux 与 macOS 启动探针均产生机器可读结果；麒麟安装后验证服务结束而图形安装器不长时间停在 1%。

## 自动回滚

数据库迁移、程序启动或健康检查任一失败时，安装事务恢复上一版二进制、配置、证书和数据库快照。网络地址事务可独立回滚旧地址和旧主机证书，并通知协同机在宽限期内退回旧地址。回滚不删除业务附件、接收文件、备份或用户数据。

## 卸载保护

“仅删除程序并保留数据”不执行数据目录删除预检。选择完整删除时必须通过目录所有权、符号链接、重解析点、挂载点和内容白名单检查；失败自动降级为保留数据卸载，禁止使用宽泛路径或递归命令强删。
