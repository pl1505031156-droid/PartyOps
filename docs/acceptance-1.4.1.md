## 本地智能

- embedding 与 LLM 已按能力独立激活，兼容旧组合包。
- BGE 清单支持 CLS 池化、查询前缀、最大长度、维度、来源哈希和许可。
- 共享文件正文默认不索引；仅发布人或管理员逐目录开启，并在撤权/停用时清理相应正文向量。
- Windows、UOS amd64/arm64 打包输入均固定 llama.cpp `b10331`；Windows 运行时 `llama-server --version` 已返回 10331。
- 当前没有可再分发的正式 `.onnx`、`.gguf` 权重和模型签名密钥，因此未生成三个 `.partyops-modelpack`，不能宣称安装即推理。
