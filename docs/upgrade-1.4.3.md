# 党建智办 PartyOps 1.4.3 安装、升级与回滚

版本：`1.4.3`；数据库：`0018`；更新包最低版本：`1.3.4`。

## 升级前

1. 确认主机和协同机角色配置，记录当前版本、架构和最近一次有效备份。
2. 校验安装器或统一更新包 SHA-256、Authenticode 与 Ed25519 签名。缺少正式签名时只能在隔离测试机验证。
3. 停止新的大文件传输，完成数据库在线快照和完整 `.partyops-backup`。

## 0018 迁移

`0018` 新增党员发展补充材料模板和条目。国家时间规则在程序中不可修改；备忘录和计算草稿不进入数据库。升级保留 `0017` 的文件共享、设备、权限、传输、档案和模型数据。

升级失败时执行器恢复升级前程序与数据库。`0018 → 0017` 会删除补充材料模板；如果已写入正式单位模板，优先恢复升级前完整备份，不要把结构降级当作长期回滚方案。

## 验证

- `/api/v1/health`：应用 `1.4.3`、数据库 `0018`、冻结 SQLite `3.53.4` 或更高。
- 普通用户能进入备忘录和党员发展计算；不能进入补充材料管理。
- 另一台电脑登录同一账号看不到原电脑备忘录和计算草稿。
- Word 能下载并打开，包含规则版本、时间轴、材料、条款、风险和人工确认项。
- 协同共享、文档阅读、重要档案和更新备份回归无倒退。

正式放行仍以 [1.4.3 发布就绪判定](release-readiness-1.4.3.md) 为准。
