# 【已撤回】党建智办 PartyOps 1.4.5-rc.3

撤回时间：2026-08-26（北京时间）

`v1.4.5-rc.3` 已停止推荐下载和在线更新。请暂时使用已验证的 `v1.4.5-rc.2`，不要使用 rc.3 覆盖现有 rc.2 数据目录。

## 撤回原因

rc.3 在数据库仍处于迁移 `0023` 时，升级前备份流程错误地使用了 `0024` 的 `BackupRun` ORM 模型。旧库缺少 `deleted_at` 等新字段，因此会在真正开始 SQLite 在线备份和迁移之前启动失败。已确认受影响数据库的 `PRAGMA quick_check` 为 `ok`，该问题不是数据库损坏，也不是 SQLite DLL 故障。

## 用户处置

- 已遇到 `[SQLITE_RUNTIME_FAILED]` 的用户不要删除 `PartyOps-Data`、数据库或备份目录；原 `0023` 业务数据库没有被本次失败迁移修改。
- 暂时重新安装 rc.2 程序并保留原数据，或等待 rc.4 修复版。
- rc.4 将使用不依赖当前 ORM 的 SQLite 在线快照，在迁移成功后才登记备份记录，并对升级失败执行校验后的原子恢复。

本 Release 及原制品仅为审计保留，不再作为可用版本。正式修复将使用新标签 `v1.4.5-rc.4`，不会移动或覆盖本标签。
