# 党建智办 PartyOps 1.4.4 发布说明

`1.4.4` 从 rc.9 增量升级，集中修复协同凭据失效、跨平台静默启动、文件打开、用户生命周期和任务改期通知，并增加会议筹备、结构化在线文档和发展党员持久档案。本版数据库模式为 `0020`，安装器在升级前备份数据库、配置、证书和绑定状态；健康门禁失败时恢复上一份快照。

## 启动、安装与协同

- 协同代理配置升级到协议 v2，记录运行时、架构和凭据状态；旧令牌有效时自动换发哈希存储的设备令牌，401/403 时停止无限灾备重试并进入“需要重新授权”，保留本地数据和绑定信息。
- 页面打开、心跳和灾备同步互不阻塞。UOS/麒麟 ARM64 的旧绑定即使暂时失效，也不再拖住桌面入口。
- 新增“网络与协同”设置，区分自动探测、监听和对外公布地址；修改前校验地址并更新证书 SAN，失败状态可回滚。
- Windows 个人模式遇到策略拒绝 HKCU 自启动时退回当前用户启动目录；自启动失败只产生可修复警告，不再误报整个模式回滚失败。
- Windows 安装器继续在目标机真实启动最终冻结 EXE，并验证原生依赖、SQLite/FTS5、迁移、端口、健康端点、运行版本和首页；`CHILD_EXITED` 会保留子进程输出。
- macOS Finder 入口使用原生 Mach-O 前置探针，在 Python 启动前写入架构、资源、PID、退出码和 stderr。Apple Silicon 与 Intel 必须分别在原生 macOS 运行器构建并执行 LaunchServices 自检。
- Linux 桌面入口先写日志，再启动配置/个人/主机/协同模式；只按安装路径、实例标识和精确进程身份处理 PartyOps 自有旧进程。

## 文件、用户与通知

- 原始文件打开授权改为数据库持久化、只存哈希、五分钟有效且数据库原子一次性兑换；服务重启后仍可区分无效、已用、过期、撤销和文件不可用。
- PDF 使用同源内联响应；WPS 等无法结构化阅读的格式明确切换到本机 WPS 或下载，不再显示空白预览。
- 用户支持编辑姓名、角色、状态和权限；删除采用“停用 → 责任移交 → 归档”，撤销会话和设备令牌，禁止删除当前用户或最后一名管理员，并可审计恢复。
- 任务日期、状态或参与人变化后立即重算通知；同一提醒窗口更新未读正文和时间，撤销失效未读通知，已读历史保留审计。

## 会议、文档与发展党员

- 内置党委会筹备六步模板：议程起草、人员通知、资料准备、资料打印、会议记录、会后纪要；每步支持负责人、状态、逾期、必交文档和总体进度。
- 月度模板可幂等生成会议实例；年度统计只计算已完成会议、已审议议题和已确认资金。
- 议程、通知、纪要等结构化文档支持在线查看、自动保存、修订历史、并发版本校验和 DOCX 导出；任意外部 WPS/DOCX 不承诺浏览器内原格式编辑。
- 发展党员档案持久保存党委、支部、人员信息、申请/积极分子/发展对象/预备/转正日期及联系人；法定边界、参考计划、人工调整和实际日期分栏存储。
- 一键生成只填法定最早/截止和参考计划，不把计算日期伪装成组织已经作出的决定；默认在 60、30、14、7、1 天和逾期提醒。
- 规则版本为 `2026.05`，依据 2026 年修订的《中国共产党发展党员工作细则》；档案汇总支持 Word 和 Excel 导出。

## 兼容性与已知限制

- Windows 10/11 x64、Win7 SP1 x64/x86、Linux AMD64/ARM64、macOS Apple Silicon/Intel 只有在对应构建与验收记录存在时才提供下载，实际状态以 `support-matrix-1.4.4.json` 和发布清单为准。
- Windows 11 ARM64、Linux i686、ARMv7、LoongArch64、RISC-V64 当前没有通过对应原生/self-hosted 构建和真机验收，标记为 `unavailable`，不得使用其他架构安装包代替。
- Windows 安装器没有商业 Authenticode 签名，可能出现 SmartScreen 信誉提示。只在官网/GitHub 官方来源与 SHA-256 完全一致时按官网步骤继续。
- macOS PKG 没有 Apple Developer ID 和公证。Gatekeeper 在程序执行前阻止时不会产生 PartyOps 启动日志；只能在核对来源和 SHA-256 后使用 Finder Control 点按或“隐私与安全性 → 仍要打开”，不得关闭 Gatekeeper。永久消除提示需要 Developer ID 签名、公证和 staple。
- Win7 已停止系统级安全维护，只建议在隔离、受控局域网使用；PartyOps 无法恢复操作系统本身的安全支持。

## 升级与回滚

1. 升级前在“备份与灾备”完成一次备份，并退出正在运行的 PartyOps 页面。
2. 从官网选择与系统、包格式和处理器架构完全一致的一个安装包，核对 SHA-256 后原位安装，无需卸载旧版。
3. 数据库由 `0019` 增量迁移至 `0020`；安装后健康门禁失败时恢复二进制、配置和数据库快照。
4. 协同机若显示“需要重新授权”，由主机管理员确认一次即可恢复，不要删除本地配置或业务数据。

规则来源：[共产党员网发展党员专题](https://www.12371.cn/special/fzdy/)；macOS 平台要求：[Apple 公证文档](https://developer.apple.com/documentation/security/notarizing-macos-software-before-distribution)；Windows 信誉机制：[Microsoft SmartScreen 文档](https://learn.microsoft.com/en-us/windows/apps/package-and-deploy/smartscreen-reputation)。
