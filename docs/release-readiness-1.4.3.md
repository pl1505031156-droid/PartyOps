## 阻断稳定发布

| 阻断项 | 当前证据 | 关闭标准 |
| --- | --- | --- |
| Windows 10 与完整角色矩阵 | 当前机器完成 Windows 11 自动化和候选流程；未覆盖 Win10 和真实多机四角色 | Win10/Win11 各覆盖主机、协同机、管理员、普通用户并归档日志 |
| UOS 双架构 | 已生成并校验原生构建套件，无当前 UOS amd64/arm64 真机构建和运行证据 | 两种架构原生构建 DEB，分别验证主机与协同机 |
| 大文件与长稳 | 无 1.4.3 的 20GB、断线、重启、撤权和 24 小时正式记录 | 保存哈希、重试、资源曲线和最终一致性证据 |
| 正式签名 | Windows 候选 Authenticode 状态为 `NotSigned`；当前环境未提供 Ed25519 发布私钥 | EXE Authenticode 有效；更新包 Ed25519 与部署公钥匹配；逐一验签 |
| 三平台正式制品 | 只有未签名 Windows 候选和 UOS 原生构建套件 | 生成两个真机 DEB 和统一签名更新包，并完成升级/回滚 |
| GitHub 历史 PR 缓存 | 本地 Git 历史与当前工作区扫描无泄密，但 GitHub Support 尚未确认历史缓存引用清理 | Support 明确确认缓存引用处理完成 |

源码环境 SQLite 版本不代表制品。已冻结的 Windows 候选实测 SQLite `3.53.4`；后续 UOS 冻结运行时也必须达到 `3.51.3` 以上，当前发布基线统一要求 `3.53.4` 或更高。

## 放行规则

任一阻断项未关闭都不得创建稳定 `v1.4.3` 标签或把安装器称为正式包。可以创建不可变 `v1.4.3-rc.2` Pre-release，并在 README、Release 正文、安装器旁的候选清单中重复标注未签名和未完成平台矩阵；rc.1 保留为历史但标记已被 rc.2 取代。
