## 公开限制与回滚

Windows 7、国产 Linux 与 macOS 缺少用户真机交互验收，不宣称已获真实使用验证。Windows 安装器没有商业代码签名证书，可能触发 SmartScreen；macOS PKG 没有 Developer ID 与公证，需要在核对哈希后使用系统“仍要打开”，不得关闭 Gatekeeper。Windows/Linux 应用更新失败使用包内回滚事务和升级前数据快照；macOS 本版不发布应用内更新包。官网可回滚 EdgeOne 页面部署，GitHub 历史 Release 用于审计与应急取回，官网只展示最新 rc.8 下载。
