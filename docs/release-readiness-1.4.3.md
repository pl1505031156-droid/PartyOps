## 线上放行条件

1. CloudStudio 先上传 rc.4，核验完整下载的长度、Magic 与 SHA-256；下载入口必须支持 Range 206 或由 EdgeOne 下载加速层提供可续传/分段缓存。
2. 新文件全部核验后，官网存储只精确删除 rc.3/rc.2 等旧安装包，不删除计数数据、更新日志或 rc.4 文件。
3. GitHub 创建 `prerelease=false`、`make_latest=false` 的普通 Release；源码、README、标签、发布说明和资产清单保持一致。
4. EdgeOne 只部署到 `makers-gjuf8qcecmi3`。官网重新执行测试、构建和桌面/移动端回归，验证下载、更新日志、简历、二维码与全局下载计数。

## 公开限制与回滚

Windows 7 与国产 Linux 缺少对应真机，不宣称原生运行验收通过。Win7 仅建议在受控局域网使用；x86 不含语义重排和本地 LLM。所有 rc.4 安装器未做商业代码签名。

应用更新失败使用内嵌 rc.3 包和升级前数据快照自动回滚；网站可回滚 EdgeOne 部署，但官网存储按用户最新要求只保留最新版安装包，不再依赖旧 CloudStudio 文件作为回滚源。任何线上哈希、范围响应或静态资源验证失败，停止后续发布且不删除旧官网安装包。
